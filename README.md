# srckit-json

> Part of [srckit](https://github.com/srckit-org/srckit) — developer tools suite

Format, validate, query, and sort JSON data with real-time feedback.

## Features

- **Formatter** — Format or minify JSON with configurable indentation (2/4/8 spaces), shows key/array/depth stats
- **Validator** — Real-time JSON validation with error messages and line numbers
- **Path Eval** — Evaluate dot-notation paths against JSON data (e.g., `data.items[0].name`)
- **Sorter** — Alphabetically sort all object keys for canonical JSON comparison

## Tech Stack

React 19 · MUI 9 · Tailwind CSS 4 · TypeScript 6 · Vite 8

## Getting Started

```bash
npm install
npm run dev
```
